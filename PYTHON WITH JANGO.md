### &#x09;	**SOFTWARE**

**SOFTWARE IS  BLOCK OF CODE WHICH IS USED TO DESIGN FOR SPECIFIC TASK**

**IT IS DIVIDED IN TO TWO CATEGORIES**

1. **SYSTEM SOFTWARE**
2. **APPLLICATION**

#### **SYSTEM SOFTWARE**

**A SOFTWARE WHICH IS NEEDED TO RUN IS CALLED SYSTEM SOFTWARE**

**EX. OPERATING SYSTEM, DRIVER ,ANTI VIRUS**

#### **APPLICATION SOFTWARE**

**APPLICATION SOFTWARE IS DESIGN FOR DIFFERENT DIFERENT PURPOSES LIKE OFFICE WORKING ACCOUNTING SOFTWARE.**



**PYTHON USING BOTH TYPE OF SOFTWARE APPLICATION AS WELL AS SYSTEM SOFTWARE**



**IN UBUTU OS PYTHON SETUP IS INSTALLED BY DEFAULT THAT MEANS IT IS ALSO USING DESIGN SYSTEM SOFTWARE TOOLS**



**1.CONSOLE APPLICATION**

**2. WINDOWS APPLICATION**

**3. MOBILE**

**4.WEB**

**5.SCIENTIFIC AND NUMERIC**
